教程文档

无心工具箱与 Android 开发的全面指南和教程。

简介 #

欢迎来到没有心科技教程文档。在这里您将找到关于无心工具箱的详细使用指南，从基本的设备连接，到高级的分区管理和刷机操作。

无心工具箱是一款功能强大的 Android 调试与刷机工具箱，支持所有常见的 ADB 和 Fastboot 命令。无论您是初学者还是有经验的开发者，本教程都能帮助您充分发挥其功能。

💡 开始之前
请确保您的设备已开启 USB 调试并安装了必要的驱动。详情请参阅安装指南。

安装指南 #

无心工具箱目前支持 Windows 平台。按照以下步骤开始使用。

系统要求

  • 操作系统：Windows 10 / Windows 11（64位）
  • 内存：4GB 及以上
  • 存储：500MB 可用空间
  • USB 接口用于连接设备

下载安装

  1. 从下载中心下载最新版本。
  2. 解压压缩包到任意目录。
  3. 以管理员身份运行 WuxinTools.exe。
BASH 复制 
# 解压并运行
cd WuxinTools
.\WuxinTools.exe

快速上手 #

安装完成后，按以下步骤快速上手无心工具箱。

  1. 通过 USB 数据线连接 Android 设备。
  2. 在设备上开启 USB 调试（设置 → 开发者选项 → USB 调试）。
  3. 启动无心工具箱，它将自动检测您的设备。
  4. 使用主界面执行各类命令。
✅ 提示
如果设备未检测到，请尝试重新连接 USB 线或重新安装驱动。

设备连接 #

无心工具箱支持 USB 和无线两种连接方式。以下是连接设备的方法。

USB 连接

  1. 使用 USB 线连接设备。
  2. 在设备上允许 USB 调试授权。
  3. 无心工具箱将在仪表盘显示设备信息。

无线连接（ADB over Wi-Fi）

  1. 确保设备和电脑在同一网络下。
  2. 先通过 USB 连接设备，然后运行：
BASH 复制 
adb tcpip 5555
adb connect 192.168.1.100:5555

将 192.168.1.100 替换为设备的 IP 地址，可在 Wi-Fi 设置中查看。

ADB 命令 #

无心工具箱提供了丰富的 ADB 命令。以下是一些常用命令。

命令 说明
adb devices 列出已连接的设备
adb shell 进入设备 shell
adb reboot 重启设备
adb reboot bootloader 重启到 Bootloader
adb reboot recovery 重启到 Recovery
adb install <apk> 安装 APK
adb push <local> <remote> 推送文件到设备
adb pull <remote> <local> 从设备拉取文件

Fastboot 命令 #

Fastboot 模式用于底层设备操作。常用命令包括：

命令 说明
fastboot devices 列出 Fastboot 设备
fastboot flash <partition> <img> 刷写分区
fastboot boot <img> 临时启动镜像
fastboot reboot 重启设备
fastboot getvar all 获取设备变量

分区管理 #

无心工具箱提供了直观的分区管理界面，您可以轻松查看、备份和恢复设备分区。

备份分区

  1. 从列表中选择要备份的分区。
  2. 点击"备份"按钮。
  3. 选择保存位置并确认。

恢复分区

  1. 在分区管理界面点击"恢复"按钮。
  2. 选择备份的镜像文件。
  3. 确认操作开始恢复。
⚠️ 警告
分区操作具有一定风险，操作不当可能导致设备无法启动。请确保提前备份重要数据。

刷机指导 #

刷写 ROM 是 Android 爱好者的常见操作。按以下步骤安全刷机。

  1. 下载您设备型号对应的 ROM 包。
  2. 备份重要数据。
  3. 将设备重启到 Fastboot 模式。
  4. 使用无心工具箱中的刷机工具刷写 ROM。
  5. 刷写完成后重启设备。
BASH 复制 
# 刷写 boot 分区示例
fastboot flash boot boot.img

# 刷写系统分区
fastboot flash system system.img

# 刷写完成后重启
fastboot reboot

动态分区 #

动态分区是 Android 10 引入的新特性，允许灵活的分区管理。无心工具箱完全支持动态分区操作。

通过动态分区支持，您可以：

  • 查看当前动态分区布局
  • 调整动态分区大小
  • 创建和删除动态分区
  • 刷写镜像到动态分区
📖 了解更多
动态分区管理是一个复杂的话题，请参考无心工具箱中的详细文档了解更多。

常见问题 #

问：设备无法被检测到？

答：请确保设备已开启 USB 调试。尝试重新连接 USB 线或更换数据线。如果问题仍然存在，请重新安装设备驱动。

问：ADB 命令无法执行？

答：确保无心工具箱以管理员权限运行。部分命令需要提升权限才能正常执行。

问：无心工具箱是否支持 Linux/Mac？

答：目前无心工具箱仅支持 Windows 平台。Linux 和 Mac 版本正在开发中。

故障排除 #

如果您在使用无心工具箱时遇到问题，请尝试以下解决方案：

  • 重启无心工具箱并重新连接设备。
  • 检查最新版本，必要时进行更新。
  • 访问我们的社区论坛寻求帮助。
  • 通过联系我们页面提供的渠道与我们取得联系。
🚨 重要
如果操作后设备无法正常启动，请尝试进入 Recovery 模式进行恢复出厂设置，或重新刷写官方 ROM。
