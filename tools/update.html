记录每一次进步，持续优化体验

v1.2.4 2026年6月18日

功能新增与体验优化和问题修复

  • 全新小米万能线刷，自动跳过各种检查，无视版本，稳定性与速度都有提升，比官方 Miflash 体验好
  • 全新主题切换系统，支持深色浅色进行完美切换
  • 全新增加两种布局，底部菜单模式和悬浮菜单，支持玻璃效果和切换动画
  • 全新设置页面，将关于板块合并至设置页，更加符合使用体验
  • 重新整理部分 UI，将进度条、滚动条、标题栏、弹窗等等基本完成统一
  • 优化去除 AVB 2.0 检验逻辑
  • 修复命令行工具设置显示欢迎语选项逻辑问题
  • 优化 USB 监控器逻辑，使得连接更加流畅
  • 更新 ADB 和 fastboot 工具和相关依赖
v1.1.3 2026年4月27日

问题修复与优化

  • 修复命令行工具文件拖放路径格式问题，现在自动转换为 Windows 路径格式
  • 修复命令行工具 hdc shell 不支持 TTY 模式的警告问题，优化命令执行和输出显示
  • 修复命令行工具中的命令超时后提示符重复显示的问题，确保命令执行流程正常
  • 修复命令行工具 adb shell 交互式命令卡住并且无法执行的问题
  • 修复命令行工具中的设置选项选择保存后会自动清空当前输出的问题
  • 修复命令行工具中的主题切换导致文字颜色显示异常的问题
  • 修复命令行工具中的滚动到最新输出选项不可用的问题
  • 修正 SELinux 合并规则工具的文档说明，明确全程在开机状态下操作
  • 修复 SELinux 日志抓取秒数计算不准确的问题，现在使用实际时间戳确保精确
  • 优化命令行工具的超时处理逻辑，提升长时间运行命令的稳定性
v1.1.2 2026年4月15日

新增功能与功能优化

  • 新增完整的文件管理功能，支持批量操作复制、剪切、粘贴、删除等，同时支持解压缩、查看校验、文件拖拽上传、高级搜索、双击文件直接用电脑打开等
  • 新增合并SELinux规则工具，支持批量处理logcat文件并合并规则，支持三种导出格式（te、cil、android sepolicy），支持智能去重和优化危险规则
  • 优化仪表盘功能，更快的CPU监控实时显示，同时支持更多CPU监控逻辑，支持新老机型，同时优化型号获取逻辑，更快更稳
  • 修复偶现仪表盘连接设备后显示未连接并且抽搐的问题
  • 修复部分情况下字体大小显示异常的问题
v1.0.1 2026年4月12日

优化与修复

  • 优化重启管理的读取设备信息速度
  • 修复双击img文件时窗口不弹出的问题
  • 修复右键菜单跳转后侧边栏选中状态不更新的问题
  • 修复安装程序和卸载程序无法申请管理员权限的问题
  • 优化和加固安装程序，避免被当病毒处理
v1.0.0 2026年4月11日

初始发布

  • 智能设备管理：实时检测ADB和Fastboot设备，显示详细设备信息
  • 分区管理工具：支持普通分区和动态分区管理
  • 重启管理：支持多种重启模式
  • Payload解包工具：支持Android 10+的Payload镜像格式
  • 命令行工具：内置ADB、Fastboot、HDC三种命令行工具
  • 驱动安装：一键安装Android设备驱动
  • 现代化界面：采用Material Design风格，界面简洁美观
  • 文件关联：支持双击镜像文件自动刷入
