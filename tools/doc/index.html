快速入门#

无心工具箱是一款基于 ADB 和 Fastboot 协议的 Android 设备管理工具，提供图形化界面，无需记忆命令行即可完成刷机、分区管理、文件操作等任务。

💡 建议在使用前开启设备的 USB调试 和 OEM解锁 选项，路径为：设置 → 关于手机 → 连续点击版本号7次 → 开发者选项 → USB调试 / OEM解锁。

安装与配置#

无心工具箱为 Windows 平台应用，下载安装程序后运行即可完成安装。

  1. 前往 下载页面 获取最新版本安装程序
  2. 双击运行安装程序，按提示完成安装
  3. 安装完成后，从桌面或开始菜单启动 无心工具箱
  4. 首次运行时，Windows 可能弹出安全提示，点击"更多信息"→"仍要运行"
💡 工具箱支持双击 .img 镜像文件自动刷入，安装后会自动关联文件格式。
⚠️ 安装时如遇杀毒软件拦截，请添加信任。工具箱不含任何恶意代码，拦截为误报。

首次连接设备#

连接设备前，请确保已完成以下准备工作：

  • 手机已开启 USB调试
  • 使用数据线连接电脑（部分线缆仅支持充电，请确认支持数据传输）
  • 手机弹出"允许USB调试"提示时，勾选"始终允许"并点击"确定"

连接成功后，工具箱将自动检测设备，仪表盘页面会实时显示设备信息。若设备未识别，可尝试：

  1. 点击 安装驱动 安装 Android USB 驱动
  2. 更换数据线或USB接口
  3. 在设备管理器中检查设备状态

设备仪表盘#

仪表盘是工具箱的首页，连接设备后自动读取并展示以下信息：

  • CPU核心利用率 / 实时频率 — 可视化展示各核心负载
  • 设备型号、Android版本、厂商、制造商
  • 序列号、CPU架构、SoC型号
  • 内存大小、存储空间 — 含已用/可用空间
  • 电池状态、网络类型、屏幕分辨率

所有数据实时刷新，无需手动操作。

分区管理#

分区管理分为 普通分区管理 和 动态分区管理 两个模块。

普通分区管理

适用于传统分区结构的设备，支持以下操作：

  • 刷写分区 — 将 .img 镜像文件写入指定分区
  • 擦除分区 — 清除指定分区的数据
  • 格式化数据 — 重置用户数据分区
  • 去除AVB2.0验证 — 解除Android Verified Boot校验
  • 切换槽位 — 在A/B双系统分区间切换
  • 去除FRP锁 — 绕过谷歌工厂重置保护
  • 解锁/上锁BL — 控制Bootloader的锁定状态

动态分区管理

专为搭载动态分区（Dynamic Partition）的设备设计，在普通分区功能基础上额外支持：

  • 调整逻辑分区大小 — 灵活分配super分区内的空间
  • 逻辑分区管理 — 创建、删除与配置逻辑分区
🔴 分区操作具有风险，错误的刷写或擦除可能导致设备无法启动。操作前请务必备份重要数据，并确认选择了正确的分区和镜像文件。

普通分区管理详解#

快速入门

本工具可以帮助您管理Android设备的分区，包括刷入镜像、擦除分区、解锁/上锁BL等功能。工具已内置fastboot功能，无需额外安装。

使用前请确保：

  • 设备已进入Fastboot模式
  • 使用质量好的数据连接

基本操作流程：

  1. 将手机进入Fastboot模式（关机后按住音量减+电源键）
  2. 用数据线连接手机和电脑
  3. 点击【读取设备信息】获取设备信息
  4. 点击【读取分区列表】查看所有可用分区
  5. 根据需要选择要刷入、擦除或格式化的分区
  6. 点击对应按钮执行操作
💡 支持右键菜单直接刷入镜像文件，自动化程度高，操作更便捷！在 .img / .bin / .elf 文件上右键点击，选择【使用无心工具箱刷入】，或直接双击文件即可自动跳转刷入。

右键菜单自动刷入

核心亮点：

  • 智能分区识别 — 自动从文件名提取分区名（如 boot.img 识别为 boot 分区）
  • 自动设备检测 — 自动检测设备连接状态，无需手动操作
  • 智能分区匹配 — 支持直接匹配和A/B槽位智能匹配
  • 动态分区支持 — 自动识别动态分区设备，智能选择刷入策略
  • A/B槽位处理 — 自动判断是否需要刷入A/B两个槽位
  • 单例模式 — 确保只有一个程序实例运行，避免冲突

智能识别机制：

  • 直接匹配：boot.img → boot 分区
  • A/B槽位匹配：boot.img → boot_a 分区（当前槽位）
  • 支持格式：.img、.bin、.elf
  • 大小写不敏感：BOOT.img → boot 分区
  • 下划线支持：system_ext.img → system_ext 分区

A/B槽位智能处理：

  • 动态分区设备：如果匹配到A/B槽位分区，自动勾选【刷入AB】；super 和 cust 分区特殊处理，只刷入当前槽位
  • 非动态分区设备：直接刷入匹配的分区，不涉及A/B槽位处理

如果自动识别失败，程序会提供回退方案：显示分区选择对话框，用户可以手动选择目标分区。

基础概念

什么是Fastboot模式？
Fastboot是Android设备的特殊模式，用于刷机操作。

  • 进入方法：手机关机后，同时按住【音量减键】和【电源键】不放，直到进入Fastboot界面
  • 退出方法：按住电源键10秒以上，或使用 fastboot reboot 命令重启

什么是分区？
Android系统将存储空间划分为多个区域，每个区域称为分区。

  • 动态分区设备：有 super 分区作为容器，system、vendor、product 等作为逻辑分区在 super 内部，可以动态调整分区大小，需要使用Fastbootd模式操作
  • 非动态分区设备：没有 super 分区，boot、system、vendor 等都是独立的物理分区，分区大小固定，直接在Fastboot模式操作

常见分区：

  • boot：启动分区，包含内核和启动文件
  • system：系统分区，包含Android系统文件（非动态分区）
  • vendor：厂商分区，包含厂商定制的驱动和配置（非动态分区）
  • super：超级分区，包含多个逻辑分区（动态分区）
  • userdata：数据分区，存储用户数据和应用数据
  • recovery：恢复分区，包含恢复模式程序

什么是BL锁？
BL锁（Bootloader锁）是厂商设置的安全机制。锁定状态下无法刷入非官方系统，解锁后可以刷入第三方系统、获取Root权限等。解锁BL锁会清除所有数据，解锁后部分银行应用可能无法使用。

什么是FRP锁？
FRP（Factory Reset Protection）是谷歌的账号锁机制。当设备恢复出厂设置后，需要输入之前登录的谷歌账号才能使用。去除FRP锁可以绕过这个验证，重新激活设备。仅用于恢复自己设备的所有权，请勿用于非法用途。

什么是AVB校验？
AVB（Android Verified Boot）是Android的启动验证机制。开启AVB时，系统会验证每个分区的完整性，如果分区被修改则无法启动。去除AVB校验后可以刷入修改过的系统镜像，但会降低系统安全性。

什么是A/B分区？
现代Android设备采用A/B分区机制，每个分区都有两个副本（A槽和B槽）。系统更新时在非活动槽位安装更新，更新成功后切换到新槽位，如果更新失败可以回退到旧槽位。

设备连接

  1. 将手机关机
  2. 同时按住【音量减键】和【电源键】不放
  3. 直到屏幕显示Fastboot界面（通常是机器人或文字）
  4. 用数据线连接手机和电脑
  5. 点击【读取设备信息】确认连接成功
⚠️ 使用原装或质量好的数据线，劣质数据线可能导致连接不稳定。操作过程中请勿断开数据线，确保设备电量充足（建议50%以上）。

读取设备信息

读取设备信息可以获取设备的详细信息，包括：

  • 设备型号和序列号
  • BL锁状态（已锁定/已解锁）
  • 是否支持动态分区（super分区）
  • 当前槽位（A槽/B槽）
  • 安全启动状态（已开启/已禁用）
  • 是否支持A/B分区

读取设备信息不会修改设备数据。如果读取失败，请检查设备连接状态。

读取分区列表

读取分区列表可以获取设备上所有分区的详细信息，包括分区名称、大小、类型和槽位信息。分区列表会显示在界面右侧的分区列表卡片中，您可以勾选要操作的分区。

读取分区列表前必须先读取设备信息。不同槽位的分区会分别显示（如 boot_a 和 boot_b）。

刷入分区

刷入分区可以将镜像文件（.img 格式）写入到设备的指定分区。

常见用途：

  • 刷入修改过的 boot 镜像（获取Root权限）
  • 刷入第三方Recovery（如TWRP）
  • 刷入修改过的 system 镜像
  • 刷入去除AVB校验的 vbmeta 镜像
  • 恢复官方分区镜像

操作步骤：

  1. 在分区列表中勾选要刷入的分区（只能选择一个）
  2. 点击【刷入分区】按钮
  3. 在文件选择对话框中选择对应的镜像文件
  4. 确认后开始刷入，等待完成
  5. 刷入完成后，建议重启设备
🔴 刷入前必须先解锁BL锁。刷入的镜像文件必须与设备型号匹配，刷入错误的镜像可能导致设备无法启动。本工具只支持刷入一个分区，动态分区设备可以刷入 super 分区（包含多个逻辑分区）。

擦除分区

擦除分区会清空分区中的所有数据，相当于格式化该分区。

常见用途：清除缓存分区、清除数据分区、修复分区错误、为刷入新镜像做准备。

操作步骤：

  1. 在分区列表中勾选要擦除的分区（可多选）
  2. 点击【擦除分区】按钮
  3. 确认操作后开始擦除
  4. 等待擦除完成
🔴 擦除 boot、system 等关键分区会导致设备无法启动。擦除 data 分区会清除所有用户数据，不可恢复。擦除操作不可逆，请谨慎操作。

格式化数据

格式化数据会清除 userdata 分区的所有内容，包括所有应用数据、下载的文件、照片视频、系统设置、联系人短信等，相当于恢复出厂设置，但不会清除系统分区。

常见用途：

  • 清除病毒或恶意软件
  • 解决系统卡顿或错误
  • 清除所有用户数据
  • 准备出售或赠送设备

操作步骤：

  1. 确保设备已连接到电脑
  2. 点击【格式化数据】按钮
  3. 确认操作后开始格式化
  4. 等待格式化完成，设备会自动重启
  5. 重启后需要重新设置手机
⚠️ 格式化前必须先解锁BL锁。格式化数据会清除所有用户数据，不可恢复，操作前请务必备份重要文件。支持动态分区的设备会额外擦除 metadata 分区。

重启设备

重启设备功能可以让设备重新启动，包括以下选项：

  • 重启设备 — 正常重启设备，进入Android系统
  • 重启到Fastbootd — 重启到Fastbootd模式（用于动态分区操作）

重启设备会断开连接，操作完成后需要重新连接。重启到Fastbootd模式需要设备支持动态分区。

解锁BL锁

解锁BL锁可以解除厂商设置的安全限制，解锁后可以刷入第三方系统、获取Root权限、修改系统文件等。

本工具提供两种解锁方案：

  • 方案一： fastboot flashing unlock（适用于大多数新机型，如realme、一加、Pixel等）
  • 方案二： fastboot oem unlock（适用于老设备和moto设备，如小米/红米、华为等）

解锁步骤：

  1. 确保设备已连接到电脑
  2. 点击【解锁BL锁】按钮
  3. 选择解锁方案（推荐使用方案一）
  4. 确认操作后，在设备上按音量键确认解锁
  5. 等待解锁完成，设备会自动清除所有数据并重启
🔴 解锁BL锁会清除所有数据，不可恢复。解锁后部分银行应用可能无法使用，部分设备无法进行OTA升级，设备安全性会降低。

上锁BL锁

上锁BL锁可以恢复设备的安全限制，上锁后可以恢复设备安全性、使用银行应用等需要安全环境的软件、恢复官方保修（部分厂商）。

本工具提供两种上锁方案：

  • 方案一： fastboot flashing lock（适用于大多数型号）
  • 方案二： fastboot oem lock（适用于老设备和moto设备）
🔴 上锁前必须将所有分区恢复到官方状态。如果修改了分区直接上锁，可能导致设备无法启动。上锁会清除所有数据。

去除FRP锁

FRP（Factory Reset Protection）是谷歌的账号锁机制。去除FRP锁可以绕过谷歌账号验证，重新激活设备。

本工具会根据设备类型自动选择操作方式：

  • 动态分区设备：先重启到Fastbootd模式，然后擦除FRP分区
  • 非动态分区设备：直接在Bootloader模式下擦除FRP分区
⚠️ 去除FRP锁仅用于恢复自己设备的所有权，请勿用于非法用途。

去除AVB校验

AVB（Android Verified Boot）是Android的启动验证机制。去除AVB校验后可以刷入修改过的系统镜像、修改系统分区文件、使用Magisk等Root方案、刷入第三方系统。

本工具通过刷入去除AVB校验的vbmeta镜像来实现，支持的vbmeta分区：

  • vbmeta / vbmeta_a / vbmeta_b
  • vbmeta_system / vbmeta_system_a / vbmeta_system_b
  • vbmeta_vendor / vbmeta_vendor_a / vbmeta_vendor_b

操作步骤：

  1. 在分区列表中勾选vbmeta分区
  2. 点击【去除AVB校验】按钮
  3. 选择vbmeta镜像文件
  4. 确认后开始刷入
  5. 等待刷入完成
⚠️ 去除AVB校验会降低系统安全性，可能导致某些安全应用无法使用。工具会自动使用 --disable-verity 和 --disable-verification 参数。

槽位切换

现代Android设备采用A/B分区机制，切换槽位可以在两个系统之间切换、回退到之前的系统版本、测试新系统而不影响旧系统。

切换步骤：

  1. 确保设备已连接到电脑
  2. 点击【切换槽位】按钮
  3. 确认操作后开始切换
  4. 切换成功后，需要重启设备
  5. 重启后进入新槽位的系统
💡 槽位切换仅支持支持动态分区的设备。切换前请确保目标槽位有可启动的系统，如果目标槽位没有系统，设备可能无法启动。可以再次切换回原来的槽位。

常见问题

Q: 设备无法连接怎么办？

  1. 检查数据线是否正常
  2. 尝试更换USB接口
  3. 确认设备已进入Fastboot模式
  4. 安装USB驱动
  5. 尝试使用其他电脑

Q: 刷入后设备无法启动？

  1. 尝试进入Recovery模式清除缓存
  2. 刷入官方镜像恢复系统
  3. 检查镜像文件是否损坏
  4. 确认镜像是否与设备型号匹配
  5. 尝试重新刷入原镜像

Q: 解锁BL锁后银行应用无法使用？

这是正常现象，解锁后设备安全性降低，银行应用会检测到并拒绝运行。解决方案：上锁BL锁、使用Magisk隐藏Root、使用虚拟机运行银行应用。

Q: 擦除data分区后数据能恢复吗？

不能。擦除 data 分区会永久清除所有用户数据，无法恢复。操作前请务必备份重要文件。

Q: 如何判断设备是否支持动态分区？

  1. 读取设备信息，查看是否有 super 分区
  2. 使用命令：fastboot getvar has-super-partition
  3. 通常Android 10及以上的设备支持动态分区

Q: 设备变砖了怎么办？

  1. 尝试进入Fastboot模式
  2. 尝试进入Recovery模式
  3. 刷入官方镜像恢复系统
  4. 使用9008模式深度刷机（需要专业工具）
  5. 联系售后或专业维修

重启管理#

一键控制设备进入不同的启动模式：

  • 重启系统 — 正常启动进入Android系统
  • 重启到Recovery — 进入恢复模式，用于刷机与备份
  • 重启到Fastbootd — 进入Fastbootd模式，用于管理动态分区
  • 重启到EDL — 进入紧急下载模式（9008），用于底层刷写
💡 重启到EDL模式需要设备支持高通9008模式，部分设备可能需要硬件短路触发。

文件管理#

通过ADB连接，在电脑端直接浏览与管理Android设备文件，支持以下操作：

  • 复制、剪切、粘贴、删除 — 基础文件操作，支持批量处理
  • 新建文件夹 — 在指定路径创建新目录
  • 高级搜索 — 按文件名快速查找设备中的文件
  • 推送文件 — 从电脑传输文件到设备指定路径，支持拖拽上传
  • 解压缩 — 在设备端直接解压压缩包
  • 查看校验 — 查看文件MD5/SHA校验值，验证文件完整性

常见问题#

设备连接后无法识别？

  1. 确认已开启USB调试并授权电脑
  2. 尝试点击"安装驱动"安装Android USB驱动
  3. 更换数据线或USB接口
  4. 在设备管理器中检查是否有黄色感叹号

刷写分区后设备无法开机？

请确认刷入的镜像文件与设备型号和分区完全匹配。如果设备支持A/B分区，尝试切换到另一个槽位启动。若仍无法解决，可通过Fastboot重新刷写正确的镜像。

动态分区和普通分区有什么区别？

动态分区（Dynamic Partition）是Android 10引入的新分区方案，将多个系统分区打包在super分区中，可动态调整大小。如果您的设备是Android 10及以上版本，通常使用动态分区管理。

工具箱支持哪些操作系统？

目前仅支持 Windows 平台，建议 Windows 10 及以上版本。
